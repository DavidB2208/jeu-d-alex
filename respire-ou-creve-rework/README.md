# Respire ou Crève — Rework Alex

Cette version ajoute un dossier standalone du jeu avec :
- des assets SVG transparents
- des passifs et améliorations achetables dès le début
- les nouvelles sources passives : Coeur artificiel, Baby Alex, Clone d'Alex, Cyber Alex, Mega Alex et God Alex
- Battements comme amélioration répétable du clic
- Ventoline comme pouvoir actif à niveau
- un départ volontairement très dangereux

Fichier principal :
- `respire-ou-creve-rework/index.html`
